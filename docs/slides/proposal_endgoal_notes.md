## 2. Where the thesis stands
Three settings, each answered on held-out pieces. The attribution result
is the honest summary of what the graph does: two-beat smoothing. Two
gaps: which score structure beyond time matters, and what the
representation is for. Say that the second proposal closes both.

## 3. The two options at a glance
Read the "question" row first, then "risk". Option 1 has no hypothesis;
option 2 can fail cleanly. Cost is comparable.

## 4. Option 1: feedback against a reference
Walk the pipeline top to bottom: the reference performance is what the
model conditions on, the student's performance is scored note by note
against the posterior, and a note is flagged only when it leaves the
model's own band. Everything in the blue box exists today.

## 5. Option 1: the feedback view (mock)
Hand-set numbers. The point is the form: the band is the model's
uncertainty, not a fixed tolerance.

## 6. Option 2: the concept
Grey edges are what the graph has now. Blue edges are new: a note is
connected to the same position in every other occurrence of its motif.
The hidden note has its counterparts observed, which is the condition
the three spans never had.

## 7. Option 2: methodology
Same model, one more adjacency term, its weight learned by the evidence.
Four arms, paired. The masking rule targets motif notes with an observed
counterpart. Data: 25 of the 32 annotated first movements are in ASAP.
Hypotheses H1 and H2 and the falsification rule are written before the
first run.

## 8. Option 2: mock results
Panel A is the decisive figure of the study; the pitch arm is there for
scale. Panel B is the application view, free from the same posterior.
Say "mock" out loud.

## 9. Plan and recommendation
Five working days, then one pre-specified evaluation if the development
result warrants it. Either outcome is a finding. Recommend option 2;
option 1 can be built on top. The writing freeze is reopened for this one
study.
